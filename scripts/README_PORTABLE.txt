DocForge Desktop v0.1.0 - Portable Windows x64

Uso local:
1. Extrae este archivo ZIP completo en una carpeta con permisos de escritura.
2. Ejecuta docforge-desktop.exe.
3. No necesitas instalar Python: el motor incluido se encuentra en binaries\.
4. LibreOffice es opcional y solo se necesita para convertir documentos Office.

Los resultados se guardan en la carpeta configurada desde Ajustes. Para verificar
la integridad del paquete, compara el SHA-256 con SHA256SUMS.txt.
